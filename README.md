# 同桌传

同桌传 2.2 用于 Windows 电脑之间发送文字和文件。两端运行同一个 [同桌传.exe](dist/同桌传.exe)，首次配对后，软件会记住设备并自动重连。适用于装有 .NET Framework 4.8 的 Windows 10 和 Windows 11。局域网发现和联系人列表的交互参考了 [LAN Messenger](https://github.com/lanmessenger/lanmessenger)。

## 首次配对

1. 把 `dist` 文件夹里的 **同桌传.exe** 复制到两台电脑上，分别双击运行。
2. 两台电脑连到同一局域网。在第一台点击 **显示配对码**，保持窗口打开。
3. 在第二台打开 **我的设备**，选中第一台，点击 **配对此设备**。输入第一台显示的 12 位配对码，点击 **连接**。

附近列表为空时，点击 **输入配对码**，手动填写对方显示的 IPv4 地址、端口和配对码。也可以在创建端点击 **复制邀请**，粘贴到加入端的 **对方地址或完整邀请** 一栏。邀请 10 分钟内有效，成功连接后失效。有多张网卡时，选另一台电脑能访问的地址。

## 日常使用

- **我的设备** 显示已配对的电脑和局域网内正在运行同桌传的附近设备。首次配对后，只要两边的程序都开着、网络可达，就会自动重连。绿色圆点表示已经建立加密连接。局域网发现可用时，电脑更名或 IP 变化后也能按设备身份找回。
- **最近会话** 按最近收发时间排列，显示最后一条消息或文件名。点开设备即可查看对应记录。查看其他会话时，后台收到的消息会显示未读数，当前输入的草稿留在原会话中。给已配对的设备发送文字、文件或文件夹时，离线任务会保存在本机，重启后仍可补发。
- **断开** 暂停本次运行中与该设备的自动重连，点击 **恢复连接** 可以恢复。要长期解除配对，从会话右上角 **··· → 取消与此设备的配对** 操作。已有聊天记录和收到的文件仍可打开。
- **托盘与通知**　关闭主窗口后仍可收件。双击托盘图标可恢复窗口，点击收件通知可打开对应会话，右键托盘图标选择 **退出** 可结束程序。通知的显示方式由 Windows 通知设置控制。
- **从 2.0 升级**　先退出两端的旧程序，再替换 EXE。原有配对和记录会被沿用。两端都升级到 2.2 后支持离线补发、去重、文件夹和断点续传。连接旧版时仍可在线收发文字和单个文件。
- **从 1.0 升级** 时，将两台电脑上的程序都更新为 2.2 并配对一次。旧版按电脑名保存的记录会独立出现在最近会话中。遇到同名电脑时，新会话按各自的设备身份区分。与 1.0 的手动配对仍可用于当次收发。

## 发送与接收

- **文字**　输入后按 Enter 发送，Shift + Enter 换行。点击消息旁的 **复制** 可复制全文。
- **文件**　点击 **发送文件** 选择一个或多个文件，也可以把文件拖入窗口。两台电脑可以同时收发。大文件分块传输，传输期间可以继续发消息。
- **粘贴**　在输入框按 Ctrl+V 可粘贴资源管理器中复制的文件，也可粘贴截图。截图会先显示缩略图和目标设备，点击 **发送截图** 后才加入队列。
- **文件夹**　点击 **发文件夹** 或拖入目录，核对文件数、总大小和目标设备后发送。接收端还原目录结构和空目录。目录链接和联接点会提示重新选择。
- **离线队列**　任务按设备保存在发送端；两端程序同时在线时自动补发。文字和文件可以同时发送。源文件移动或修改后，可从对应气泡 **重新选择**、**重试** 或 **取消**。
- **接收位置**　默认保存在 Windows 的 **下载 → 同桌传** 文件夹。点击左下角 **接收文件夹** 打开目录，点击 **更改** 为后续接收选择其他位置。
- **完成状态**　发送方看到 **对方已接收** 时，对方已确认收到。文件会先校验 SHA-256，再以最终名称保存。同名文件自动添加序号。2.2 配对设备会保留中断的部分，重连时两端校验已有前缀，再继续传剩余内容。接收端按设备和传输编号保存回执，重启或确认丢失后重试也只保存一份。
- **会话文件**　点击会话右上角 **会话文件**，按名称、扩展名（如 `.pdf`）或收发日期筛选。类型输入「文件夹」可查目录。双击结果可在资源管理器中定位。
- **记录保留**　默认保留最近 200 条已完成记录。在会话文件窗口可选 7、30、90 天或长期；设置适用于本机所有会话。接收文件单独保存在接收目录。
- **本机数据**　历史、待发送记录和去重回执使用 Windows 当前账户加密，位于 `%LOCALAPPDATA%\TongZhuoChuan`。粘贴图片保存在其中的 `screenshots`，待发送文件夹使用临时 ZIP 快照，完成或取消后清理。接收中的部分文件保存在接收目录。

## 连接排查

- 首次运行时，如果 Windows 防火墙询问是否允许访问，请允许同桌传访问当前使用的可信专用网络。
- 附近设备发现使用 IPv4 组播 UDP 42864，自动重连默认使用 TCP 42863。配对窗口的查找功能使用 UDP 42862，首次连接的 TCP 端口默认是 42861。默认 TCP 端口被占用时，软件会选择可用端口并通知对端。
- 自动重连通过双向 TLS 核验首次配对时交换的设备证书。设备私钥和配对记录由 Windows 当前用户加密保护。局域网组播被过滤时，软件还会尝试配对时或上次连接时保存的地址。
- 访客 Wi-Fi 可能隔离不同电脑。跨网络使用时，两台电脑需要通过同一 VPN 等方式获得互相可达的 IPv4 地址，再手动填写创建端的地址。软件使用 TLS 1.2 传输数据。

## 编译与验证

使用 Visual Studio 2022 的开发者命令提示符，安装 .NET 桌面开发工具和 .NET Framework 4.8 目标包。在本目录执行以下命令。

```bat
msbuild DeskLink.csproj /p:Configuration=Release
msbuild Tests\TransferSmoke.csproj
Tests\bin\DeskLink.Smoke.exe
```

使用原始 2.0 程序验证升级兼容性时，运行 `Tests\bin\DeskLink.Smoke.exe upgrade "旧版同桌传.exe的完整路径"`。

主程序的输出文件是 `dist\同桌传.exe`。测试覆盖首次配对与重连、双向文字和文件、旧版兼容、双进程离线队列和断点恢复、回执丢失后的重试、文件夹还原，以及实际 WPF 窗口的截图预览、文件粘贴、托盘收起与恢复、搜索和记录保留。
